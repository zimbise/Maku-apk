# Maku APK

A torrent application for Android using WebView.

## Building the Debug APK

### Prerequisites

- Java Development Kit (JDK) 17 or higher
- Android SDK (automatically downloaded by Gradle)

### Build from Source

1. **Clone the repository:**
   ```bash
   git clone https://github.com/zimbise/Maku-apk.git
   cd Maku-apk
   ```

2. **Build the debug APK:**
   ```bash
   cd android
   ./gradlew assembleDebug
   ```
   
   On Windows, use:
   ```cmd
   cd android
   gradlew.bat assembleDebug
   ```

3. **Find the APK:**
   The debug APK will be located at:
   ```
   android/app/build/outputs/apk/debug/app-debug.apk
   ```

### Install the APK

You can install the APK on your Android device using:

```bash
adb install android/app/build/outputs/apk/debug/app-debug.apk
```

## Getting Pre-built APKs

Pre-built debug APKs are automatically generated by GitHub Actions on every push to the `main` branch.

### Download from GitHub Actions:

1. Go to the [Actions tab](https://github.com/zimbise/Maku-apk/actions)
2. Click on the latest successful workflow run
3. Scroll down to the "Artifacts" section
4. Download `maku-apk-debug`
5. Extract the ZIP file to get the APK

### Manual Trigger:

You can also manually trigger a build:

1. Go to the [Actions tab](https://github.com/zimbise/Maku-apk/actions)
2. Select "Build APK" workflow
3. Click "Run workflow"
4. Wait for the build to complete
5. Download the artifact as described above

## Development

### Clean Build

To clean the build artifacts:

```bash
cd android
./gradlew clean
```

### Build Release APK

To build a release APK (requires signing configuration):

```bash
cd android
./gradlew assembleRelease
```

## Troubleshooting

### Gradle Build Issues

If you encounter build issues, try:

1. Clean the build:
   ```bash
   ./gradlew clean
   ```

2. Clear Gradle cache:
   ```bash
   rm -rf ~/.gradle/caches/
   ```

3. Ensure you have JDK 17 or higher:
   ```bash
   java -version
   ```

### Android SDK Issues

The Gradle build will automatically download the required Android SDK components. If you encounter SDK-related errors, ensure you have an internet connection during the first build.
